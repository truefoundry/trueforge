Replace the composer's attach button and Tools pill with a single plus (+) menu offering Add Files or photos, Connectors (with the built-in TrueForge and Web search toggles), Skills, and Environment, and show selected connectors and skills as chips beside it. The New Agent composer uses the same plus button, and a plus with only one action runs it directly without opening a menu. Compact layouts open the menu as a bottom sheet with drill-down sections.
