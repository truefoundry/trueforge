Agents often hit decision points they should not guess — which environment to deploy to, which of several matches the user meant, or what an ambiguous required field should be. **Ask User Questions** pauses the agent, shows a multiple-choice prompt, and resumes with the chosen answer.

It is **enabled by default**.

## Configuring

<Note>
  Enabling or disabling Ask User Questions (`config.ask_user_questions`) is configured via the **API / SDK** today. The
  chat UI already renders questions and collects answers. See the [agent spec](/api/agent-spec#config).
</Note>

## How it feels in chat

The agent asks a structured question with options. The user picks one (or types a free-form answer). The agent continues from where it paused.

## When to use it

- Choosing a target environment, cluster, account, or workspace
- Disambiguating multiple matches ("I found 3 services named `api` — which one?")
- Filling required fields the user did not specify
- Picking a strategy before a destructive or expensive step

Skip it when the agent can confidently infer the answer from context — over-asking turns the agent into a form.
