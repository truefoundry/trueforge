---
title: "Agent modes"
description: "Choose between a fixed agent, a library, a composer, or both."
---

This can be configured by using the `agentConfig` object.

```ts
type AgentConfig =
  | { mode: "SingleAgent"; name: string } //name is agent name
  | { mode: "AgentLibrary" }
  | { mode: "AgentComposer" } //Composer is agent creation flow
  | { mode: "AgentLibraryWithComposer" }; //Default mode
```

| Mode | Library | Composer | New chat |
| --- | --- | --- | --- |
| `SingleAgent` | — | — | Yes |
| `AgentLibrary` | Yes | — | No |
| `AgentComposer` | — | Yes | Yes |
| `AgentLibraryWithComposer (Default)` | Yes | Yes | Yes |

## Single Agent

All chats are done with one named agent which can be configured in `name`  param. All selection controls are hidden and the user cannot switch agents or open the composer.

## AgentComposer

Users compose/create a new agent by selecting models, skills, MCP servers and can save it to the library.

<Frame>
  ![Agent Composer 1](/images/agent-composer-1.png "Agent Composer 1")
</Frame>

## AgentLibrary

Users chat with agents already saved in your library but cannot compose a new one. Note that “new chat” is disabled in this mode only. Ideally for restricting agent creation by users.

<Frame>
  ![Agent Library 1](/images/agent-library-1.png "Agent Library 1")
</Frame>

## AgentLibraryWithComposer

Users can pick an existing agent from the library or create a new one.
