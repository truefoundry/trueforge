The sidebar view is the default option. You can pass predefined values - sidebar, drawer, dock, or widget to change the layout.

<Tabs>
  <Tab title="sidebar(default)">
    Full-page chat with a persistent chat history on the left. The default choice for a dedicated chat surface.

    ```tsx
    <TrueForgeUI server={server} layout="sidebar" />
    ```

    <Frame caption="Sidebar: full-page chat with the thread list pinned on the left.">
      ![Sidebar layout — a persistent thread list on the left beside a full-page chat](/images/sidebar.png)
    </Frame>
  </Tab>
  <Tab title="drawer">
    Chat history list collapses into an overlay drawer. Click on the history icon to view the past conversations. Suited to narrower viewports.

    ```tsx
    <TrueForgeUI server={server} layout="drawer" />
    ```

    <Frame caption="Drawer: the thread list collapses into an overlay for narrow viewports.">
      ![Drawer layout — the thread list collapsed into an overlay drawer](/images/drawer.png)
    </Frame>
  </Tab>
  <Tab title="dock">
    A panel pinned to the right edge, filling the available width up to a 400px cap.

    ```tsx
    <TrueForgeUI server={server} layout="dock" />
    ```

    <Frame caption="Dock: a compact panel pinned to the right edge, up to a 400px cap.">
      ![Dock layout — a compact chat panel pinned to the right edge of the app](/images/dock.png)
    </Frame>
  </Tab>
  <Tab title="widget">
    Floating launcher that expands into a compact chat panel.

    ```tsx
    <TrueForgeUI server={server} layout="widget" />
    ```

    <Frame caption="Widget: a floating launcher that expands into a compact chat panel.">
      ![Widget layout — a floating launcher expanded into a compact chat panel](/images/widget.png)
    </Frame>
  </Tab>
</Tabs>

Built-in layouts are code-split, so using one does not pull the other three into your bundle. A placeholder renders for the moment it takes to load.
