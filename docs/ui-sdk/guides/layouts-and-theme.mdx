## Preset Layouts

The sidebar view is the default option. You can pass a predefined value - sidebar, drawer, dock, or widget to change the layout. You can also build a complete custom layout using the predefined components as [shown here](/ui-sdk/setup-custom-ui/custom-layout).

## Preset Themes

You can choose from four preset themes - Claude, ChaptGPT, Gemini, TrueFoundry or you can create a [custom theme](setup-custom-ui/).

## The theme object

```ts
type ThemeConfig = {
  preset?: "trueforge" | "claude" | "chatgpt" | "gemini"; // default "trueforge"
  mode?: "light" | "dark" | "system";
  brand?: {
    name: string; // required when `brand` is set
    logo?: string | BrandLogoConfig;
  },
  ...
};
```

```tsx App.tsx
<TrueforgeUI
  ...
  theme={{
    preset: "claude",
    mode: "system",
    brand: {
        name: "TrueForge",
        logo: "/logo.svg",
    }
  }}
/>
```

## Light and dark mode

When you skip this key then the SDK defaults to system theme. User will get an option to switch to dark or light theme via UI.

If you want to control the theme based on the app level theme then pass a value to set a theme to light, dark or system to match the main app theme. Please note, user does not get an option to update it via UI.

### Set separate logo for light and dark theme

You can also provide different logos for dark and light mode as shown below: 

```tsx App.tsx
<TrueforgeUI
  ...
  theme={{
    ...
    brand: {
      name: "TrueForge",
      logo: {
        light: "/logo/light.svg",
        dark: "/logo/dark.svg",
        href: "https://trueforge.dev", // URL to redirect on logo click
      },
    }
  }}
/>
```

The source is picked from the resolved mode, so this follows the system theme when `mode` is
omitted. Set only one of `light` / `dark` and it is used for both modes; use `src` for a
mode-agnostic mark. `name` labels the image, and the link when `href` is set.

To render a component instead of an image — an inline SVG, an animated mark — override the
`BrandLogo` slot rather than passing a node through `theme`:

```tsx App.tsx
<TrueforgeUI ... overrides={{ BrandLogo: MyMark }} />
```
