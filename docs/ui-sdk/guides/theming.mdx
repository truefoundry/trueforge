You can choose from four preset themes - Claude, ChaptGPT, Gemini, or TrueFoundry

## The theme object

```ts
type ThemeConfig = {
  preset?: "truefoundry" | "claude" | "chatgpt" | "gemini"; // default "truefoundry"
  mode?: "light" | "dark" | "system";
  brand?: {
	name?: string;
  	logo?: string | BrandLogo;
  },
  ...
};
```

```tsx App.tsx
<TrueforgeUI
  ...
  theme={{
    preset: "claude",
    mode: "system",
    brand: {
        name: "TrueForge",
        logo: "/logo.svg",
    }
  }}
/>
```

## Light and dark mode

Skip means defaults to system theme. User can choose via UI.

Pass to set a theme to light, dark or system. User CANNOT update it. This is useful when you want to control the theme based on the main/top level app theme.

### Set separate logo for light and dark theme 

```tsx App.tsx
<TrueforgeUI
  ...
  theme={{
    ...
    brand: {
        name: "TrueForge",
        logo: {
		  "light": "/logo/light.svg",
		  "dark": "/logo/dark.svg",
		  "href": "https://trueforge.dev" //URL to redirect on logo click
        },
    }
  }}
/>
```
