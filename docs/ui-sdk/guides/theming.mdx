You can choose from four preset themes - Claude, ChaptGPT, Gemini, or TrueFoundry

## The theme object

```ts
type ThemeConfig = {
  preset?: "truefoundry" | "claude" | "chatgpt" | "gemini"; // default "truefoundry"
  mode?: "light" | "dark" | "system";
  brandName?: string;
  brandLogo?: string;
  className?: string;
  icons?: IconMap;
  classNames?: ContentClassNames;
};
```

```tsx App.tsx
<TrueforgeUI
  ...
  theme={{
    preset: "claude",
    mode: "system",
    brand: { name: "Acme", icon: { src: "/logo.svg", alt: "Acme" } },
  }}
/>
```

## Light and dark mode

Skip `theme.mode` to set the theme as system. and the provider is uncontrolled: it resolves `system`, lets the user toggle, and persists the choice to `localStorage` under `aui-theme-preference`. Pass `theme.mode` and the provider becomes controlled — `setTheme` from `useTheme()` becomes a no-op and you own the state.

<Warning>
  Dark mode toggles the `dark` class on `document.documentElement`. If your app already manages dark mode by the same mechanism, the two will fight. Pass a controlled `theme.mode` derived from your own state to keep them in sync.
</Warning>
