## Installation

<CodeGroup>

```shellscript npm
npm install @truefoundry/trueforge-ui
```

```text pnpm
pnpm add @truefoundry/trueforge-ui
```

```text yarn
yarn add @truefoundry/agent-ui-sdk
```

</CodeGroup>

`react` and `react-dom` are required peer dependencies and must be version 18 or 19.

## Connect with TrueForge Server

Typed for hosts adopting the harness adapter.

```tsx
<TrueforgeUI
  server={{
    type: "trueforge",
    apiKey: {{API_KEY}},
  }}
  layout="sidebar"
/>
```
