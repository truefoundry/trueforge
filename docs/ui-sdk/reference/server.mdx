## Factory

```ts
createTrueFoundryServer(options: CreateTrueFoundryServerOptions): TrueFoundryServer;
```

Options: `{ chatServer, getCapabilities, getModels, getSkills, getMcp, searchAgents, saveAgent, deleteAgent?, catalog? }`.
Combines a chat server with your agent-management callbacks into a complete `AgentUIServer`.
`deleteAgent` and `catalog` are the only optional entries; if you omit `deleteAgent`, calling it
throws.

## Context

| Export | Behavior |
| --- | --- |
| `ServerProvider` | Supplies the resolved server. |
| `useServer()` | The server; throws outside a provider. |
| `useOptionalServer()` | The server, or `null` outside a provider. |
| `useServerCapabilities()` | Resolved `getCapabilities()` data, or `null` while loading or on failure. |
| `useCatalogServer()` | `server.catalog`; **throws** when absent. |
| `useOptionalCatalogServer()` | `server.catalog`, or `null` when there is none. |

## Shell mode

| Export | Behavior |
| --- | --- |
| `ShellModeProvider` | Derives shell capabilities from `agentConfig`. |
| `useShellMode()` | Throws outside a provider. |
| `useOptionalShellMode()` | Returns `null` outside a provider. |
| `DEFAULT_AGENT_CONFIG` | `{ mode: "AgentLibraryWithComposer" }`. |

`useShellMode()` reports which surfaces the current `agentConfig` permits —
`isLibraryEnabled`, `isComposerEnabled`, `isNewChatEnabled` — and returns the actions
`selectAgent`, `openDraft`, and `clearChat`, plus `settingsOpen` / `setSettingsOpen`. Use it in
a custom layout to render only the controls that apply. See
[Agent modes](/ui-sdk/concepts/agent-modes).
