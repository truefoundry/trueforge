---
title: "TrueForge UI SDK"
description: "A themeable React SDK for building AI agent chat applications."
---

`@truefoundry/trueforge-ui` is a React component that embeds an agent chat UI into your app.

Features:

- **Agent modes**: chat with a single agent, browse an agent library, or let users create and compose agents.
- **Chat**: streaming responses, session history, tool calls with approval workflows, and file attachments.
- **Themes**: built-in Claude, ChatGPT, Gemini, and TrueFoundry presets, plus custom themes.
- **Layouts**: full-screen with a sidebar or drawer, or embedded dock and floating widgets.
- **Integration settings**: models, MCP servers, skills, and sandbox environments.
- **Server configuration**: TrueForge, a fully custom server, or TrueFoundry.

<br />

## Interactive controls and code examples

The hosted webapp at [https://ui.trueforge.dev/](https://ui.trueforge.dev/) lets you configure component props, override defaults, and copy a generated snippet into your app.
