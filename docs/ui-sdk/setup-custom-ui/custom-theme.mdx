## The theme object

Pass design tokens on the theme object to override component styles. You can also override app-level CSS classes for broader layout and styling changes.

```jsx App.jsx
type ThemeConfig = {
  ...
  tokens?: Partial<SemanticTokens>;
  icons?: IconMap;
  ...
};
```

## The token object

Override individual design tokens to change colors and other visual properties: sidebar, page background, popups, buttons, inputs, and the rest of the surfaces listed below.

Set tokens separately for light and dark mode so both schemes stay consistent without per-component CSS.

The fastest way to try tokens is the [UI Config App](https://ui.trueforge.dev/). Change colors in the preview, then copy the generated config into your app.


```json Token Object
{
  "light": {
    "sidebarBg": "#FAFAFA",
    "primaryBg": "#FFFFFF",
    "textPrimary": "#18181B",
    "primaryButtonBg": "#6366F1",
    "userMessageBg": "#6366F1"
    // ...others (see the full list below)
  },
  "dark": {
    // ...same tokens as light mode
  }
}
```

Values above are an example brand override, not the built-in preset defaults.

### All tokens

See [Token naming](#token-naming) for how each key maps to a CSS variable.

| Token name | Description |
| --- | --- |
| `sidebarBg` | Thread-list / nav rail background. Sidebar, chat history, chat drawer. |
| `topbarBg` | Shell and modal headers. Sidebar and drawer layout chrome, centered modal headers. |
| `primaryBg` | Page canvas — thread, settings body, dock/widget chrome. Background color of all pages. |
| `secondaryBg` | Icon wells, soft chips, and secondary nav tracks. |
| `border` | Dividers and outlines. Panel edges, list rows, cards, and form fields. |
| `fontFamily` | Base UI font across the SDK shell. |
| `inputBoxBg` | Input and composer surfaces. Chat composer, search fields, shared text inputs. |
| `inputBorder` | Borders on text inputs and outline / secondary buttons. |
| `textPrimary` | Headings, labels, and primary body copy. |
| `textSecondary` | Muted labels, placeholders, timestamps, and helper text. |
| `cardBg` | Elevated surfaces. Dialogs, menus, tooltips, settings cards, bottom sheets. |
| `dropdownSelectedItemBg` | Selected / active menu and list rows. Dropdowns, thread list, segmented toggles. |
| `dropdownSelectedItemText` | Text on selected / active menu and list rows. |
| `userMessageBg` | User chat message bubble background. |
| `userMessageText` | User chat message bubble text. |
| `assistantMessageBg` | Assistant message bubble background (default transparent). |
| `assistantMessageText` | Assistant chat message text. |
| `primaryButtonBg` | Primary CTAs. Save, Connect, active settings tabs, widget launcher. |
| `primaryButtonHover` | Primary button hover fill. |
| `primaryButtonText` | Primary button label color. |
| `secondaryButtonBg` | Secondary / outline buttons. Cancel, Configure, and similar actions. |
| `secondaryButtonHover` | Secondary button hover fill. |
| `secondaryButtonText` | Secondary button label color. |
| `ghostButtonBg` | Ghost button background (usually transparent). Icon actions and quiet controls. |
| `ghostButtonHover` | Ghost button and row hover fill. Message actions, nav hover, menu highlight. |
| `ghostButtonText` | Ghost button icon and label color. |
| `successBg` | Success icons, status dots, and tinted success badges. |
| `successText` | Paired text color for solid success fills (rarely used directly today). |
| `failureBg` | Error banners, destructive buttons, validation errors, and denied states. |
| `failureText` | Text on solid failure / destructive fills. |
| `warningBg` | Warning pills and status dots. Editing badge, in-progress step indicators. |
| `warningText` | Text on solid warning pills. |
| `focusRing` | Focus rings on buttons, inputs, switches, and the composer. |
| `radius` | Base corner radius for buttons, cards, and controls. |
| `composerRadius` | Chat composer and user message bubble corner radius. |
| `overlay` | Modal, drawer, and mobile sidebar backdrops. |
| `shadowColor` | Elevation shadows for the dock panel and widget popup. |
| `scrollbarThumb` | Scrollbar thumb in the theme root and scrollable panels. |

## Token naming

SemanticTokens keys map directly to kebab-cased CSS variables. For example, `primaryButtonBg` maps to `--primary-button-bg`, and `userMessageText` maps to `--user-message-text`. The only exception is `fontFamily`, which maps to the `--font-agent-ui` CSS variable.

To apply a brand primary color and font across the SDK, override the matching semantic tokens:
```ts
const theme = {
  tokens: {
    primaryButtonBg: "#635BFF",
    primaryButtonHover: "#5147E5",
    primaryButtonText: "#FFFFFF",
    fontFamily: "Inter, sans-serif",
    composerRadius: "12px",
  },
};
```
Those tokens map to CSS variables:
```ts
--primary-button-bg
--primary-button-hover
--primary-button-text
--font-agent-ui
--composer-radius
```
Changing a few semantic tokens updates the UI consistently without writing component-specific CSS.

## Styling rendered content

`theme.classNames` (`ContentClassNames`) adds host CSS classes onto content renderers. Pass it through `theme` on `TrueforgeUI` (or `SlotsProvider`):

```tsx
<TrueforgeUI
  theme={{
    classNames: {
      markdown: "prose prose-sm",
      openui: { root: "my-openui" },
    },
  }}
  /* … */
/>
```

```ts
type ContentClassNames = {
  /** Root of the markdown renderer (joins `.aui-markdown`). */
  markdown?: string;
  /** Inline `` `code` `` spans inside markdown. */
  inlineCode?: string;
  syntaxHighlighter?: {
    root?: string; // joins `.aui-syntax-highlighter`
    pre?: string;
    code?: string;
    lineNumber?: string;
  };
  openui?: {
    root?: string; // joins `.aui-openui`
    scope?: string; // OpenUI theme scope (`.markdown-openui-scope`)
  };
  monaco?: {
    root?: string; // joins `.aui-monaco`
    editor?: string; // Monaco mount container
    /** Monaco theme name; when unset, follows light/dark mode. */
    monacoTheme?: string;
  };
};
```

For CSS-only adjustments you can instead target the stable class names directly: `.aui-markdown`, `.aui-syntax-highlighter`, `.aui-openui`, `.aui-monaco`.
