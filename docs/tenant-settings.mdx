Tenant settings are admin switches that allow or block a capability for everyone in the tenant. They sit above each agent's own toggles: an agent can only use a capability when the tenant allows it and a provider is configured.

In **TrueFoundry mode**, these settings are **per tenant**. Each tenant admin opens **Settings** and changes only their tenant's switches; provider catalogs stay platform-managed.

## Available settings

| Setting | Where | Default | What it controls |
| --- | --- | --- | --- |
| **Allow web search** | **Settings → Web search** | On | Whether new chats and agents may turn on [web search](/web-search). Chats that already use it keep it. |
| **Allow memory** | **Settings → Memory** | On | Whether agents may use [memory](/memory). Turning it off also stops memory in existing chats. |

Only admins can change these switches. In TrueFoundry mode, a tenant admin can open the Web search and Memory sections for the switches even when they cannot edit providers.

## Manage through the API

- `GET /api/v1/settings/configuration` reads the tenant switches.
- `PATCH /api/v1/settings/configuration` updates one or both, for example `{ "manifest": { "web_search": { "enabled": false }, "memory": { "enabled": true } } }`.
- `GET /api/v1/capabilities` reports whether web search and memory are available to agents, including when a tenant switch is off.
