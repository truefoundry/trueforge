# Security Policy

## Supported versions

Security fixes are applied to the latest published `0.x` release on npm.

## Reporting a vulnerability

Please report security issues privately to **security@truefoundry.com** (or your TrueFoundry security contact).

Include:

- Description of the issue and impact
- Steps to reproduce or a proof of concept
- Affected package version(s)

We will acknowledge receipt and work with you on a fix and disclosure timeline. Please do not open a public GitHub issue for vulnerabilities.
